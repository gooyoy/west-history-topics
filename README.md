## 🕯️ 本仓库公理（第一性原理）

> ## **「给岁月以文明——而不是给文明以岁月」**
>
> ——刘慈欣《三体·黑暗森林》

**——本仓库所说的"文明"——是中华《周易》本义**：
- "**天下文明**"（《周易·乾卦·文言》）
- "**情深而文明**"（《礼记·乐记》）
- 是以**德性之光——由内而外——照亮天下**

**——本仓库所反对的——是西方 civilization 的伪文明叙事**：
- 以进步之名屠戮 2 亿生灵
- 以自由之名奴役半个地球
- 以民主之名颠覆数十国家

**评价文明的唯一标准——是德性——不是成就**。
**成就越大、代价越重——德性可能越低**。
**中华文明 5000 年——活得最久、杀人最少——这才是"文明"本义**。

**——"文明"二字的拆解**（中华《周易》本义）：
- **"文"的教化**——向内——修己、修族群、修文化
- **"明"的德行**——向外——对他者的仁与厚
- **——缺一不配叫"文明"**——
- **——靠大屠杀、种族灭绝建立的霸权——那叫野蛮——是强权丛林披了技术外衣**——

**——"文明"的试金石——不在历史中——在当下的街头**：
- 中国：**路不拾遗、没有流浪汉、半夜出门有东西吃、外卖 24 小时、政府兜底**
- 美国：**homeless、吸毒、枪击、每 5 分钟 1 人死于绝望**
- **——不是美国做不到——是骨子里没有"文明"二字**——
- **——这种文明温度——随中国免签政策——已被 YouTube 上的外国人物理验证**——

## 整体思路说明

这一整套文件共享几个写作原则：

1. **对一个在红旗下长大、信唯物主义的中国读者说话**——不预设基督教、西方政治、冷战史的背景知识；
2. **抛开信仰和立场，走历史学和社会学**——不为任何一方辩护；
3. **看穿话语，看到结构**——每一个话题都试图拆出"它是为了解决什么问题""谁得了利""它的代价是什么"；
4. **每一讲都能独立读**，但连在一起能看到**西方 150 年精神、政治、经济演化**的全景；
5. **中国视角的对照**——每一讲尽量在结尾给出与中国经验的平行和差异。

**读完这 40 讲+附录，你对当代世界主要文明的宗教-政治底层逻辑、殖民史的真实账目、以及"温和改革者为何下场惨烈"的根本原因，理解应该超过 95% 的中文读者**——不是因为这些内容新奇，是因为这些内容在中文世界被系统性低估了。
