# 接续指令模板

> **复制下面任意一段——粘贴到新对话开场——即可**。

---

## 模板 A：极简版（推荐日常使用）

```
我有一个长期思想札记项目在 GitHub/工蜂仓库 [仓库地址]。
请先读 00-接续包/ 目录下的四个文件——5 分钟就能进入状态。
读完告诉我你抓到了几个关键点，然后我们继续聊 [今天想聊的主题]。
```

## 模板 B：标准版（推荐新模型/新平台第一次使用）

```
我有一个长期思想札记项目，已经沉淀了 31 讲 + 7 篇附录约 82 万字。

请按以下顺序快速接续：

1. 读 00-接续包/01-作者立场速查.md  → 理解我是谁、立场是什么、禁区在哪里
2. 读 00-接续包/02-写作风格样本.md  → 理解我们之间已形成的对话风格
3. 读 00-接续包/03-已讨论主题索引.md → 避免重复铺垫已讨论过的话题

读完后用 3 句话告诉我：
- 你抓到的我的核心立场是什么
- 你将采用什么样的对话风格
- 你最关注的"禁区"是什么

然后我们继续聊 [今天的主题]。
```

```
今天要讨论一个比较深的议题：[主题]。

为了避免你重复铺垫，请先做三件事：

1. 读完 00-接续包/ 全部四个文件
2. 重点查阅 [相关章节，例如 25-教员·内核面.md] 了解我已经在这个话题上的思考深度
3. 检查 03-已讨论主题索引.md 中是否有已经讨论过的相关认知工具

准备好后告诉我"准备好了"——我们直接进入正题，不需要重头解释基础概念。
```

## 给作者自己的提醒

### 何时需要"开新对话"？

- 当前对话已经超过 50-100 轮交互
- 响应明显变慢
- 感觉 AI 对早期内容"开始遗忘"
- 想换一个完全不同的主题

### 开新对话前的"自我检查清单"

- [ ] 当前对话有没有重要内容需要归档到仓库？
- [ ] 接续包是否需要更新（新增主题/立场演化/新风格表达）？
- [ ] 我有没有把上一次对话的"核心结论"先沉淀好再开新对话？

### 开新对话后的"标准动作"

1. 复制上面任一模板（推荐 B 或 D）
2. 等 AI 读完接续包并确认理解
3. 验收：让 AI 复述你的核心立场——验证它真的"接上了"
4. 进入正题
